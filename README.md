# Sales-Force-Training

##Overview
A company conducts a sales force training for their employees and is tring to figure out if it positively effects the sales

## Goal
Determining the effectiveness of sales force training towards the number of sales using descriptive statistics and statistical  testing

## Tools Used
- Python
- pandas (data manipulation)
- numpy (numerical operations)
- matplotlib (data visualization)
- seaborn (statistical visualization)
- scipy (statistical analysis)

## Results
The increase of sales from the training is not statistically significant
